### Cybersecurity direction

- **Defensive security:** file integrity, configuration review, evidence, and remediation.
- **Ethical hacking:** scoped practice in owned systems and training labs, with clear findings and retests.
- **Linux:** shell workflows, permissions, processes, services, and logs.
- **Web security:** HTTP behavior, application boundaries, authentication, and access-control concepts.
