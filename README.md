# Zubair Zahidi

Student developer and founder of **Zoderise**. I build local AI applications, productivity tools, and interactive web experiences, with a growing focus on software reliability and defensive security.

My projects span the interface, application logic, local storage, and packaging. I document how to run them and use tests to check the workflows they promise.
